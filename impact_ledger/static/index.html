Import CSV

Add session or attendance records from a CSV file. Every row must pass validation before any row is saved.

UTF-8, up to 1 MiB and 5,000 rows per file.

Import sessions first, then attendance that refers to those session IDs. Use fictional records only. Duplicate IDs are rejected.

Preview is optional. It checks the file against the current ledger without saving rows or reserving IDs. Import checks the file again before saving, because the ledger may have changed.

CSV column guide

Sessions
session_id,program,session_date,duration_hours,budget,actual

Attendance
attendance_id,session_id,participant_id

Dates: YYYY-MM-DD. Hours: 0.01–24 per session. Budget and actual: USD, nonnegative, at most two decimal places. IDs: ASCII letters, digits, dot, underscore or hyphen.

Metric guide

Reach
Unique participant IDs across selected sessions. Program totals can overlap and should not be added.
Participant hours
Each session’s duration multiplied by its attendance count. Assumes each person attends the full session.
Budget variance
Actual minus planned session spending. Percentage divides by the selected budget; no percentage is reported when budget is zero.
What the ledger does not measure
Eligibility, unmet need, attendance rate, outcomes and causal impact. The demo has no eligible-population or outcome data.
